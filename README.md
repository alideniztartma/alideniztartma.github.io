# alideniz.me

Ali Deniz Tartma'nın kişisel sitesi — açık kaynak katkıları, projeleri ve iletişim bilgileri.

Tek dosyalık statik site (`index.html`), GitHub Pages üzerinde `alideniz.me` alan adıyla yayınlanır. Derleme adımı yoktur.

- `index.html` — site (TR/EN, açık/koyu tema)
- `robots.txt`, `sitemap.xml` — arama motorları için
- `og.png`, `favicon.*` — paylaşım görseli ve simgeler
- `DESIGN.md`, `PRODUCT.md` — tasarım ve içerik kuralları
